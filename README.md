# Davidson Chiemezuo — AI Developer Portfolio

A premium, dark-themed personal portfolio designed for an Agentic AI Developer. Built with React 19, TypeScript, Vite, Tailwind CSS, and a custom WebGL matrix-rain shader.

## Features

- **WebGL Matrix Rain Hero** — Custom shader background with slate/cyan palette
- **Terminal Typing Effect** — Hacker-style text reveal in the About section
- **Scroll-Reveal Animations** — Smooth fade-in effects across all sections
- **Fluid Text Hover** — Rolling character hover effect on navigation links
- **Responsive Design** — Fully mobile-optimized layout
- **Project Modals** — Detailed project views with highlights and tech stacks

## Tech Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS
- Custom WebGL Shaders
- Lucide React (icons)

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Output goes to `dist/` for GitHub Pages deployment.

## Deployment

Configured for GitHub Pages with custom domain `david.dgi.qzz.io` via CNAME in `public/`.
